Proyectos Destacados

Algunos ejemplos de soluciones personalizadas que hemos desarrollado

AgroConecta — Marketplace Agrícola

AgroConecta es un marketplace digital que conecta directamente a campesinos, compradores y empresas para vender y distribuir productos agrícolas, gestionando pedidos, stock, logística y estados de entrega desde una sola plataforma.

Next.js + TypeScript Prisma CSS + Tailwind MySQL

Resumen

Marketplace para venta y distribución agrícola con gestión de pedidos, stock y logística.

ArisERP — ERP SaaS modular

ArisERP es un ERP SaaS modular en la nube: módulos independientes (ventas, inventario, contabilidad, RRHH, etc.) que cada empresa activa según sus necesidades.

Laravel PostgreSQL Docker Angular

Resumen

ERP modular en la nube con módulos activables por suscripción para pymes.

Tecnologías

Laravel PostgreSQL

CraftPlane — Planificador de construcciones voxel

CraftPlane es una plataforma web que permite planificar, visualizar y adaptar construcciones voxel (tipo Minecraft) antes de construirlas en el juego.

Next.js + TypeScript Tailwind Laravel MySQL WebGL

Resumen

Herramienta para planificar construcciones voxel con visualización por capas y guías de construcción.

Destacado

  • Visualización 3D
  • Guías por capas
  • Export/Compartir builds

CodeArchitech — App educativa gamificada

CodeArchiteck es una app educativa gamificada donde aprendes programación, ingeniería y arquitectura de software como si fuera un juego por mundos. Cada mundo enseña conceptos clave mediante introducciones, prácticas, retos y jefes finales.

Flutter + Dart

Qué hace

  • Enseña programación y software engineering paso a paso.
  • Organiza el aprendizaje en mundos temáticos progresivos.
  • Usa misiones, retos, experiencia, monedas y desbloqueos.
  • Evalúa tu progreso con pruebas prácticas reales.

Fin del proyecto

Formarte de manera estructurada y completa para que puedas programar profesionalmente, diseñar sistemas reales y pensar como ingeniero y arquitecto de software.

Stack tecnológico

  • Flutter para una app móvil multiplataforma fluida y atractiva.
  • Dart para lógica de la aplicación, gestión de estados y backend local.

IncubApp — Gestión de ciclos de incubación (Flutter)

App multiplataforma en Flutter para planificar y seguir ciclos de incubación: crear/iniciar/finalizar/cancelar ciclos, registrar controles diarios (temperatura, humedad, observaciones) y recibir recomendaciones automáticas.

Flutter Dart SQLite / LocalStorage

Resumen

App para planificar y seguir ciclos de incubación, registrar controles diarios y recibir alertas automáticas.

Principales funciones

  • Crear/gestionar ciclos
  • Registro diario de temperatura/humedad
  • Recomendaciones automáticas

AppCosecha — Gestión de negocios y finanzas (Flutter)

Aplicación Flutter para gestionar negocios, registrar entradas/transacciones, establecer metas, ver resúmenes e indicadores (analytics) y completar el flujo de onboarding/configuración.

Flutter Dart SQLite / Drift json_serializable

Resumen

App para gestionar negocios: transacciones, metas y métricas con persistencia local.

Funcionalidades

  • Registrar transacciones y ver resúmenes
  • Definir y seguir metas
  • Dashboards y métricas clave
